# Znacht add-on

The Znacht engine for Home Assistant OS, for households without a separate host: it plans the week's
dinners, writes them to Cookidoo My Week after you approve, and fills your Migros online and in-store
lists. It never checks out, pays or places an order.

Install the **Znacht** integration from HACS as well; it gives you the entities, the actions and the
notifications. See the Documentation tab for setup and the current limitations of the add-on.
