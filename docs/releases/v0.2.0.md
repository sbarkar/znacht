Znacht now runs entirely inside Home Assistant OS: one install from HACS, the app in the sidebar, the
first setup in Home Assistant's own forms and the app. An engine in an LXC moves over with its history.

## Install

HACS → Znacht → install, restart Home Assistant, then Settings → Devices & services → Add integration →
**Znacht** → **Run Znacht here in Home Assistant**. The integration adds the add-on repository, installs
and starts the add-on, and asks for your accounts. Open **Znacht** in the sidebar; a Welcome walks you
through your household. (A release candidate shows up in HACS with "Show beta versions" on.)

## What's new

- **The add-on is a full deployment (ADR-0012).** The app runs under Home Assistant's ingress: Home
  Assistant signs you in, no port or token needed. The add-on makes its own API token and announces itself,
  so the integration sets up with one click. Notification links open the add-on's panel.
- **One install from HACS (ADR-0013).** The integration installs, configures and starts the add-on.
  Accounts are asked in Home Assistant's forms, and a rejected password comes back on its own field. A
  failed sign-in no longer stops the engine; Connections in the app says what is wrong.
- **Welcome in the app.** People, how you cook, the delivery postcode and slot, and the two Migros lists
  picked from your account. Household edits the slot and the lists later. No file editor, no YAML.
- **Notifications in Configure.** The integration's Configure picks the phone from your Companion apps,
  next to the accounts.
- **Move from the LXC.** Put a bundle made by `deploy/lxc/bundle.sh` in the add-on's config folder and
  start it. The household, Cookidoo token, Migros session and database (run history, savings, learned
  Migros availability) are restored, the accounts go into the add-on's options, and the bundle is removed.
  Steps in the add-on's Documentation tab.
- **Releases are pinned (ADR-0015).** The add-on builds on the engine image of its own version, so a
  rebuild never picks up unreleased code.
- **Docs.** The README tells the HACS story, and the add-on documents every option.

## Fixes

- An add-on installed through the integration now shows up in the sidebar, with the watchdog on.
- Removing one Znacht entry no longer removes the other entry's sidebar panel.
- An add-on entry created from discovery can be configured (it used to say the engine runs elsewhere).
- Delivery times are quoted in the household file (YAML read an unquoted `18:00` as 1080).
- A failed setup write keeps the old household file; a missing household opens the Welcome instead of
  "Can't reach the engine"; a missing Cookidoo email no longer crashes the engine.
- The accounts form no longer shows a translation error.

## Updating from 0.1.0

The add-on store offers the update; update the integration in HACS to the same release. If you ran the
engine in an LXC, follow "Moving from the LXC" in the add-on's documentation, then remove the old
integration entry and confirm the discovered add-on.
